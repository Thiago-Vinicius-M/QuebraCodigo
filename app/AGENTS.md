# Agents

GPL agents disponíveis via Claude Code:

- **action-writer** — server actions seguindo arquitetura Epic (auth + validação + Drizzle)
- **component-writer** — React components consumindo hooks
- **hook-writer** — React hooks com state + actions + optimistic updates
- **integration-writer** — integrações externas (APIs, email, payments)
- **model-writer** — data models Active Record sobre Drizzle
- **route-writer** — HTTP routes e webhooks
- **test-writer** — testes comportamentais (.spec.ts, .action.test.ts, hook tests)
