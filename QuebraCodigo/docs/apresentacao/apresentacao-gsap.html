// TCC · Plataforma educacional

Quebra Código

Jogos interativos e trilhas de programação para praticar lógica e desenvolvimento web.

Spring Boot PostgreSQL REST API Front-end vanilla

Problema

Aprender programação pede prática constante

  • Conteúdo disperso e pouco engajador para iniciantes.
  • Falta de feedback imediato e sensação de progresso.
  • Dificuldade de unir teoria (cursos) com lógica (jogos) no mesmo lugar.

Proposta

Uma plataforma web integrada

Um único ambiente com cadastro, trilhas de cursos, minijogos, progresso e gamificação — com API REST no back-end.

Autenticação (sessão) Ranking & pontos IA opcional (Gemini)

Stack

Tecnologias principais

Back-end

Java 21, Spring Boot 3.3, JPA, validação, Flyway, BCrypt, PostgreSQL.

Front-end

HTML5, CSS3, JavaScript (vanilla), layout responsivo.

Produto

Jogos e desafios

  • Campo minado, Sudoku, Memória, Connect 4, 2048, Flow Free…
  • Quizzes e jogos de lógica (ex.: verdadeiro/falso, semáforo).
  • Experiência pensada para reforçar raciocínio antes da demo ao vivo.

Produto

Trilhas de programação

Cursos com lições em sequência (HTML, CSS, JavaScript, Python, Java, C++, TypeScript…), navegação clara e foco no progresso do aluno.

Arquitetura

API REST

  • /auth — login, cadastro, sessão, perfil.
  • /api — cursos, lições, jogos, progresso, leaderboard, gamificação.
  • /api/ia — chat com IA quando configurado (Gemini).

Demo

Mostrar na prática

Subir a aplicação (mvn spring-boot:run em app), acessar localhost:8150 e percorrer fluxo de usuário + um jogo ou curso.
